## 🚀 Quick Deploy Commands

```bash
# Vercel (1 minute)
git push origin main
# Then: vercel.com → New Project → Deploy

# Netlify (2 minutes)
npm run build
# Then: Drag dist/ to netlify.com

# Docker (10 minutes)
docker build -t idt .
docker run -p 80:80 idt

# AWS (5 minutes)
npm run build
aws s3 sync dist/ s3://my-bucket/

# GitHub Pages (5 minutes)
npm run build
git add dist/
git commit && git push

# Traditional Server (10 minutes)
npm run build
# Upload dist/ via FTP/SSH
```
